# Frontend Rules

ဤဖိုဒါသည် frontend UI/coding rules နှင့် patterns များအတွက်ဖြစ်သည်။

Add a new frontend coding rule or pattern here as a separate `.md` file
(e.g., `styling.md`, `api-service.md`, `map-patterns.md`). Every rule must
follow the project strict workflow: plan first, save in `frontend/plans/`,
wait for approval.
