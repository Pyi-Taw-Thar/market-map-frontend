# Frontend Plans

ဤဖိုဒါသည် frontend implementation plan များအတွက်ဖြစ်သည်။
- Implementation plans are auto-saved here with the date-based naming format:
`YYYY-MM-DD-short-description-plan.md` (e.g., `2026-07-27-add-shop-form-validation-plan.md`).
- Plans must be written in Myanmar Language and shown to the user for approval
before any code is written.
